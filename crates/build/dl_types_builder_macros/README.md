# dl_types_builder_macros

Part of the [`dalaran`](https://github.com/Flaminis/Dalaran) family of crates.

![MIT](https://img.shields.io/badge/license-MIT-blue.svg)
![Apache](https://img.shields.io/badge/license-Apache-blue.svg)

The `#[dalaran_type]` attribute proc-macro used by Dalaran's type definitions.

Re-exported by `dl_types_builder_prelude`, which is what the definitions actually depend on.
You almost certainly want that crate instead.
