Part of the [`dalaran`](https://github.com/Flaminis/Dalaran) family of crates.

![Apache](https://img.shields.io/badge/license-Apache-blue.svg)

Dalaran GUI theme and helpers, built around [`egui`](https://www.egui.rs/).

Defines the theme of the Dalaran Viewer, and has helpers for constructing some UI elements.

Also contains our fonts and icons.

Run the example with `cargo r -p dl_ui --example dl_ui_example`
