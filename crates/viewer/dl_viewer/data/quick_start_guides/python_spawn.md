# Python quick start

## Installing the Dalaran SDK

The Dalaran SDK is available on [PyPI](https://pypi.org/) under the
[`dalaran-sdk`](https://pypi.org/project/dalaran-sdk/) name. It can be installed like any other
Python package:

```sh
pip install dalaran-sdk
```
