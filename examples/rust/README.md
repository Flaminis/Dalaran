# Dalaran Rust examples

These are examples of how to use the [`dalaran`](https://github.com/rerun-io/rerun/tree/latest/crates/top/rerun) crate.

## Running the examples

To try out any example in the list that follows, simply run `cargo run -p <example_name>`; e.g. `cargo run -p minimal`.

By default, the examples spawn a Dalaran Viewer and stream log data to it.
In debug builds, they will spawn `target/debug/dalaran` if it exists, otherwise look for `dalaran` on `PATH`.

You can instead save the log data to an `.dlr` file using `cargo run -p objectron -- --save data.dlr`. You can then open that `.dlr` file with `dalaran data.dlr` or `cargo run -- data.dlr`.

NOTE: `.dlr` files do not yet guarantee any backwards or forwards compatibility. One version of Dalaran will likely not be able to open an `.dlr` file generated by another Dalaran version.

### Additional settings

Most examples come with a set of predefined Dalaran flags and optionally a number of example-specific flags.
Use e.g. `cargo run -p objectron -- --help` for a detailed listing.

The predefined Dalaran flags go as follow and are all mutually exclusive:
- `--spawn`: start a Viewer and feed it data in real-time (default behavior)
- `--save <SAVE>`: saves the data to an dlr file rather than visualizing it immediately
- `--connect [IP:PORT]`: connects and sends the logged data to a remote Dalaran viewer
- `--serve`: connects and sends the data to a web-based Dalaran viewer.

## Datasets

Some examples require small datasets to be downloaded before they run.
These datasets can be downloaded by running the homonymous Python examples (each example that requires it will tell you how to).

The datasets will be added to a subdir called `dataset`, which is in the repo-wide `.gitignore`.

### [`objectron`](objectron)

`cargo run -p objectron`

Demonstrates how to log:
* Points
* Images
* Camera extrinsics (rigid transform)
* Camera intrinsics (pinhole transform)

### [`raw_mesh`](raw_mesh)

`cargo run -p raw_mesh`

Reads a GLTF mesh file and logs it as either raw triangle data or a prepacked asset.

Demonstrates how to log:
* Triangle meshes
* Prepacked 3D assets
* Rigid transforms

### [`dna`](dna)

`cargo run -p dna`

This is what you'll build when following our [Getting Started guide](https://www.dalaran.dev/docs/getting-started/data-in/rust).
