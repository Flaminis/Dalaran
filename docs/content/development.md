If you want to contribute and help develop Dalaran, that work happens in the [Dalaran repository](https://github.com/Flaminis/Dalaran).

Start with [`CONTRIBUTING.md`](https://github.com/Flaminis/Dalaran/blob/main/CONTRIBUTING.md) for the development setup, commit conventions, and the DCO sign-off requirement. Design discussion happens in [GitHub issues](https://github.com/Flaminis/Dalaran/issues) and [Discussions](https://github.com/Flaminis/Dalaran/discussions).
