# Dalaran documentation

Dalaran is an Apache-2.0, robotics-first observability and visualization stack for multimodal time-series data — ROS 2 topics, LiDAR, cameras, IMU, and TF transforms, recorded and replayed on one timeline.

- [What is Dalaran?](overview/what-is-dalaran.md) — what it is, who it is for, and how the pieces fit together
- [Getting started](getting-started.md) — install it and log your first recording
- [Concepts](concepts.md) — the data model, timelines, entity paths, and chunks
- [How-to guides](howto.md) — task-oriented recipes
- [Reference](reference.md) — types, CLI flags, and per-language API docs
- [Developing Dalaran](development.md) — for people working *on* Dalaran
